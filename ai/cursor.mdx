O [Cursor](https://cursor.com) é um editor de código com IA. Você pode conectá-lo ao servidor MCP do PostClean para gerenciar seus agendamentos direto do editor.

## Pré-requisitos

- Cursor 1.0 ou mais recente (versões anteriores não suportam OAuth em servidores MCP remotos)
- Uma conta no PostClean com assinatura ativa ([planos e cobrança](/knowledge-base/settings/plans-and-billing))

## Configuração

<Steps>
  <Step title="Crie o arquivo de configuração MCP">
    Na raiz do seu projeto, crie ou edite `.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "postclean": {
          "url": "https://post.chatclean.com.br/mcp/trypost"
        }
      }
    }
    ```

    Não precisa de cabeçalho `Authorization`: o Cursor detecta o OAuth pela URL e se registra sozinho.
  </Step>
  <Step title="Entre pelo navegador">
    Abra as configurações de MCP do Cursor (ou o chat de IA) e clique em **Connect** ao lado de **postclean**. O Cursor abre uma janela do navegador com o login do PostClean. Entre na sua conta, escolha o **Workspace** que essa conexão pode usar, clique em **Autorizar** e volte ao Cursor. Para usar outro workspace, conecte de novo e escolha-o.
  </Step>
  <Step title="Confira a conexão">
    Abra o painel de chat de IA e peça:

    ```
    Liste todas as minhas contas sociais no PostClean
    ```
  </Step>
</Steps>

## Exemplos de prompts

Use o chat de IA do Cursor ou a edição inline para trabalhar com o PostClean:

```
Crie um novo post para todas as minhas contas conectadas
```

```
Mostre todas as minhas assinaturas
```

```
A qual workspace eu estou conectado?
```
