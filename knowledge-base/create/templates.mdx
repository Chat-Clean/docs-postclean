Um modelo é um texto de post reutilizável. **Criar › Modelos** reúne a biblioteca do PostClean e os modelos que a sua equipe e você escrevem. Usar um modelo coloca o texto dele no editor de posts; a partir daí ele é um post comum, que você pode mudar à vontade.

Todos os membros do workspace podem usar e criar modelos.

## Escopos

| Aba | O que tem |
| --- | --- |
| **Descobrir** | A biblioteca do PostClean, marcada **Por PostClean**. Somente leitura. |
| **Equipe** | Modelos visíveis para todos neste workspace. Qualquer pessoa do workspace pode editá-los. |
| **Pessoal** | Modelos que só você vê. |

**Descobrir** abre com **Nossas melhores escolhas**, uma lista curta de formatos que funcionam para a maioria das contas; **Ver todos** mostra a biblioteca inteira. Os modelos de Equipe e Pessoais mostram o autor (**Por** *nome*).

**Descobrir** tem uma busca e quatro filtros:

- **Tipo**: Dica, Estudo de caso, História, Passo a passo, Pergunta, Opinião, Lista, Bastidores
- **Feito para**: Empresas, Pessoas
- **Formato**: Texto único, Thread
- **Objetivo**: Engajamento, Conexão, Reflexão, Autoridade, Promoção, Educação, Celebração

## Usar um modelo

<Steps>
  <Step title="Abra">
    Clique no cartão de um modelo para ver o texto completo.
  </Step>
  <Step title="Use ou copie">
    **Usar modelo** abre o [editor de posts](/knowledge-base/publish/composer) com o texto do modelo. **Copiar modelo** copia o texto para a área de transferência.
  </Step>
</Steps>

Dentro do editor de posts, o botão **Modelos** abre as mesmas três abas num painel lateral. Escolher um modelo ali insere o texto dele no post que você está escrevendo.

## Criar um modelo

Clique em **Novo modelo** e preencha:

- um emoji
- **Título**
- **Descrição**: "Uma linha para o seu eu do futuro sobre quando usar este modelo."
- **Conteúdo**: o texto que vai para o editor de posts
- **Visibilidade**: **Somente eu** (Pessoal) ou **Minha equipe** (Equipe)

Clique em **Criar modelo**. Só quem criou pode mudar a visibilidade de um modelo.

## Duplicar, editar e excluir

No menu de um modelo:

- **Duplicar** faz uma cópia e pergunta onde salvar: **Somente eu** ou **Minha equipe**. É assim que você parte de um modelo da biblioteca e o adapta.
- **Editar** e **Excluir** aparecem nos modelos que você pode editar: todos os modelos de Equipe e os seus Pessoais.

Excluir um modelo não muda os posts já criados a partir dele.

<Note>
  Os modelos só existem no app web. Não há endpoint de API nem ferramenta MCP para eles.
</Note>
